Feekr's own interface fonts (self-hosted; both under the SIL Open Font License 1.1).

inter-*.woff2      Inter variable (wght 100–900) by The Inter Project Authors, split
                   into latin / latin-ext / cyrillic / cyrillic-ext subsets. Used as
                   "Feekr Sans". Licence: OFL-Inter.txt.

feekr-display.woff2  A modified version of Fraunces by The Fraunces Project Authors:
                   instanced at SOFT=100, WONK=0, opsz=72 (weight axis 300–800 kept),
                   subset to Uzbek Latin, and U+02BB (ʻ, Uzbek oʻ/gʻ) mapped to the
                   turned-comma glyph. Renamed "Feekr Display" as the OFL asks for
                   modified versions. Licence: OFL-Fraunces.txt.

src/app/_og/*.woff are static WOFF copies of the same two families for the
Open Graph image renderer (Satori cannot read WOFF2).
